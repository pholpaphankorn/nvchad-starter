# Neovim Image Previews

Language for viewing image files and images referenced by Markdown while working in Neovim, including previews opened in other applications.

## Language

**Image-file preview**:
A view of an image file as a picture, displayed inside Neovim or in an external image viewer.
_Avoid_: Image editing

**Browser Markdown preview**:
A rendered view of a Markdown document in a web browser, including pictures referenced by local paths or remote image URLs.
_Avoid_: Inline Markdown image

**Inline Markdown image**:
A picture displayed within the Neovim Markdown editing window from a local file reference or a remote image URL.
_Avoid_: Browser Markdown preview
